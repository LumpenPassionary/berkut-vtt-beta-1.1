# Снимок статистики физических бросков

Команда:

```bash
python -m dice_lab.stats --rolls 1000 --seed 7
```

По 1000 полных симуляций Bullet на каждый тип кубика. `seed` влияет только
на генератор начальных условий; результат каждого броска читается из
итогового поворота.

| Кубик | OK | COCKED | Хи-квадрат | df | Критич. p=0.001 | Среднее время |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| D4 | 1000 | 0 | 4.26 | 3 | 16.27 | 1.21 c |
| D6 | 1000 | 0 | 10.23 | 5 | 20.52 | 1.30 c |
| D8 | 994 | 6 | 6.42 | 7 | 24.32 | 1.58 c |
| D10 | 994 | 6 | 4.61 | 9 | 27.88 | 1.94 c |
| D12 | 994 | 6 | 17.79 | 11 | 31.26 | 2.64 c |
| D20 | 991 | 9 | 25.49 | 19 | 43.82 | 1.76 c |

Все значения хи-квадрат ниже критического при p = 0.001. Ни один кубик
не покинул лоток; нечитаемые грани составляют 0–0.9% и не заменяются
случайным числом.


Частоты D4 (1…4): `236 256 234 274`.
